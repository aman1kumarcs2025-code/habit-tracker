# HabitFlow — HTML/CSS/JS Habit Tracker

## Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server, database, Node.js, or installation is required.

## Included
- Monthly habit grid
- Add/edit/delete habits
- Daily completion checkboxes
- Monthly goal and progress bars
- Overall completion and goal statistics
- Current streak and best streak
- Previous/next month navigation
- Dark mode
- LocalStorage persistence
- Responsive mobile layout

## Data
All habit data is stored in the browser using LocalStorage. Clearing site data/browser storage will remove it.
